# This is a Project to map Gestures into transformations to an OpenGL object.

## Setup Instructions

1. Download the files into a folder named `ar_powered_design`, or update the path in `main.py`.
2. Open a terminal and create a virtual environment.
3. Install the required packages:

| Package       | Version   |
|---------------|-----------|
| absl-py       | 2.3.1     |
| cffi          | 2.0.0     |
| flatbuffers   | 25.12.19  |
| glfw          | 2.10.0    |
| mediapipe     | 0.10.31   |
| numpy         | 2.2.6     |
| opencv-python | 4.12.0.88 |
| pip           | 25.3      |
| pycparser     | 2.23      |
| PyOpenGL      | 3.1.10    |
| setuptools    | 65.5.0    |
| sounddevice   | 0.5.3     |

4. Run the main Python file:

```bash
python main.py
```
